# Habiba Akter — Portfolio

Responsive portfolio website built with React, TypeScript, Vite, React Router, and Lucide icons.

## Run locally

1. Install Node.js (LTS recommended).
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed in the terminal.

## Before submitting / publishing

Replace all placeholders with real details:

- `src/App.tsx`: update `social` links, email address, phone/contact details, education status, project descriptions, live links and GitHub repositories.
- Add your real professional portrait to `public/profile.jpg`, then update the hero profile markup in `src/App.tsx` to use that image.
- Add your actual resume as `public/resume.pdf`. The Download Resume button currently points to that path and will work after the PDF is added.
- Change `https://example.com` project links to actual live project URLs.
- Update the skills and self-assessed skill percentages to reflect your current level.

## Build

Run `npm run build`. Deploy the project folder to Vercel or Netlify. For Vercel, import the repository and use the default Vite build settings (`npm run build`, output directory `dist`). React Router routes should be supported by Vercel's SPA fallback.

## Note

This is a ready-to-customize project scaffold. No hosting account is connected, so a public live URL has not been created by this package.
